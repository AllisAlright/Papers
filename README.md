# Selected Papers GitHub Pages

这个文件夹可以直接作为一个 GitHub Pages 仓库发布。主页在 `index.html`，PDF 在 `papers/`，论文首页预览图在 `assets/`。

## 最快发布方式

1. 在 GitHub 新建一个公开仓库，例如 `papers`。
2. 把本文件夹里的全部内容上传到仓库根目录。
3. 进入仓库 `Settings` -> `Pages`。
4. Source 选择 `Deploy from a branch`。
5. Branch 选择 `main`，文件夹选择 `/root`，保存。

几分钟后页面地址通常是：

```text
https://你的GitHub用户名.github.io/papers/
```

如果仓库名是 `你的GitHub用户名.github.io`，页面地址通常是：

```text
https://你的GitHub用户名.github.io/
```

## 简历里可放的链接

主页链接：

```text
https://你的GitHub用户名.github.io/papers/
```

单篇 PDF 链接格式：

```text
https://你的GitHub用户名.github.io/papers/papers/info-age-lora-energy-harvesting-short-packet.pdf
https://你的GitHub用户名.github.io/papers/papers/information-freshness-random-access-energy-harvesting.pdf
https://你的GitHub用户名.github.io/papers/papers/spatial-capacity-random-access-poisson-networks.pdf
https://你的GitHub用户名.github.io/papers/papers/to-sense-or-not-to-sense-aoi-energy-harvesting-networks.pdf
```

如果你使用 `你的GitHub用户名.github.io` 作为仓库名，则去掉第一个 `/papers`：

```text
https://你的GitHub用户名.github.io/papers/info-age-lora-energy-harvesting-short-packet.pdf
```
